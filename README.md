# Social Media Networking System in C++

## Overview
This project is a Social Media Networking System developed in C++ that simulates the basic features of a real social media platform using Data Structures and Object-Oriented Programming concepts.

The system allows users to:
- Create and manage user accounts
- Add and remove friends
- Create posts
- Like and comment on posts
- Manage notifications
- View and upload stories

The project is menu-driven and demonstrates practical implementation of multiple data structures in a real-world application.

## Data Structures Used
| Data Structure | Purpose |
|----------------|---------|
| Linked List | User Management |
| Stack | Posts Handling |
| Queue | Notifications |
| Binary Search Tree (BST) | Friends Management |
| Circular Linked List | Stories System |
